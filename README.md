# Simple Interest Calculator

This repository contains a simple interest calculator script.

## Introduction

This is a micro-finance startup that believes in the power of open source.
This calculator computes simple interest given principal, rate, and time.

## Usage

Run the bash script and enter the required inputs:
- Principal amount
- Rate of interest (per annum)
- Time period (in years)

The script will output the calculated simple interest.
